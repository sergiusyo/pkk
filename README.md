# pkk
# Сайт продуктовой компании, коммерческий. Памашъялский песчаный карьер, тестовое задание. Одобрено. С адаптивами и JS.

<span style="font-size:12px;">Стек технолоний на проекте: HTML, CSS, JavaScript. Библиотеки JS:</span>

<div style="font-size:12px;">
<p>- JQuery-UI.</p>
<p>- Graph-modal.js: создание модальных окон.</p>
<p>- Accordion.js: создание аккордионов по клику на заголовок.</p>
<p>- Just-validate: валидация форм.</p>
<p>- Inputmask.js: создание масок ввода в полях форм.</p>
<p>- Zoom-Layout: управление Яндекс-картой в футере (https://api-maps.yandex.ru/2.1/?lang=ru_RU&apikey=<ваш API-ключ> ссылка на API-Яндекс-карт).</p>
<p>- Swiper.js: слайдеры.</p>  
</div>
